# 正式注册开放检查

## 当前状态

注册、云账户二要素核验、账号关联及注册成功自动登录已接入，本地注册开关已打开。已提供三份实际正文和独立授权勾选，不再走验证码体验分支。详细状态见[乐享借注册开放](./乐享借注册开放.md)。

已按用户提供的安据存、anjucun_admin@163.com、ajc.tingnichui.com填写实际正文；另存的“草案”文档只是起草历史，不是注册页展示来源。公网部署和法律审核仍需运营方确认，不得将本地开放视为已完成上线。

## 发布前确认

1. 提供产品名、运营主体全称和有效隐私联系渠道；确认云账户实际签约主体、联系方式及数据处理合同。
2. 确认部署地点、各类数据和备份保留期限、注销/删除流程及人工申诉渠道。草案中的流程要求须实际落实。
3. 完成协议审核，并在稳定的 HTTPS 地址发布版本化正文；不得仅配置不存在或内容为空的链接。
4. 独立实名核验授权已实现，默认不勾选；后端调用前强制检查，版本及确认时间与同版本三份正文共同留存。
5. 成年人限制已实现；核验流程仅面向本人，不因核验通过而作出信用担保。
6. 上线前更新现有旧 RSA 登录密钥方案，使用足够强度的密钥并部署 HTTPS；浏览器 RSA 不能替代 HTTPS。
7. 完成无授权、拒绝协议、验证码错误、重复注册、供应商异常和事务回滚验证；真实核验仅使用已获授权的数据。

## 配置位置

共用 application.yml 中 iou.registration 已有2026-10-10-v1及HTTPS地址默认值，允许以下环境变量覆盖：

- IOU_REGISTRATION_AGREEMENT_VERSION
- IOU_USER_AGREEMENT_URL
- IOU_PRIVACY_POLICY_URL

上述值必须对应已审核、可访问的正式正文。补齐配置只是现有代码的开启条件，不代表以上发布条件自动满足。禁止为绕过开关随意填写示例地址。

## 法律参考

参考[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)第十七条、第二十一至二十三条、第二十八至三十条及个人权利相关条款，及[民法典](https://tjca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_20cf1a2e1b854924b5caa744c8045d1f.html)关于格式条款的规定。草案应结合实际运营安排审核，不构成对业务合法性或合规完成情况的保证。
