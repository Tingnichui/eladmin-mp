# 借条用户身份证查看

借条用户管理新增身份证列，默认展示前三位、后四位，中间十一位脱敏。
点击“查看”在当前单元格显示明文，点击“隐藏”恢复脱敏。不设置自动隐藏倒计时。
查询、翻页、刷新或离开页面时清空明文；上述操作之后返回的旧请求不会重新显示明文。
明文只保存在当前组件内存，不写入浏览器存储，不进入列表接口或导出文件。

## 接口与权限

- 列表新增 `maskedIdNo` 字段，身份证密文和 HMAC 继续不返回。
- `POST /api/iouUser/{id}/identity/reveal` 返回 `idNo`，响应设置 `Cache-Control: no-store`。
- 独立权限为 `iouUser:viewIdentity`。只有列表权限不能查看明文；超级管理员沿用原有 `admin` 权限。
- 使用现有审计日志记录管理员、目标借条用户 ID、时间和成功或异常结果，不记录响应正文。
- 缺失用户、缺失密文或解密失败返回通用错误，不返回底层解密异常或敏感内容。

新环境及需要为普通角色授权时，执行 `sql/iou_identity_view_permission.sql`，在角色菜单权限中按需授予“借条用户查看身份证”。
该脚本可重复执行，只为超级管理员追加默认授权，不改借条用户数据。
角色权限变更后按现有系统流程刷新权限或重新登录。

## 验证

后端测试覆盖独立权限、不可缓存响应、列表脱敏序列化、密文解密失败和不存在的用户。
前端测试覆盖单行显示、手动隐藏、重复点击、失败恢复及刷新/离开时丢弃旧响应。
