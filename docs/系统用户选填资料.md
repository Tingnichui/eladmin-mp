# 系统用户选填资料

沿用 ELADMIN 用户管理、个人中心及现有用户服务，将电话、昵称、邮箱调整为选填，不删除字段或历史数据。

- 用户管理新增、编辑：用户名、状态、部门、岗位、角色的原有要求保持不变；电话和邮箱填写时继续校验格式并查重。后台新增默认密码仍由原 Controller 设置。
- 后端 `UserService.create/update/updateCenter` 将空白资料规范化为 NULL；没有电话、邮箱时跳过对应查重。
- 编辑和个人中心清空资料时使用局部更新条件显式写入 NULL，不修改实体全局字段策略；个人中心修改不会清空原邮箱。
- 用户列表、个人中心和在线用户页面在昵称为空时显示用户名。
- `sys_user.phone/email/nick_name` 必须允许 NULL；初始化脚本已有此定义。保留邮箱唯一索引，避免用空字符串占用唯一值。
- 2026-10-10 已只读核对本地开发数据源的实际表结构，上述三个字段均允许 NULL，无需数据库迁移。
- 本步骤不涉及借条注册接口、账号关联、角色初始化或登录参数变更。

验证命令：

```text
cd eladmin
mvn -pl eladmin-system -am -DskipTests=false -Dtest=UserOptionalProfileTest -Dsurefire.failIfNoSpecifiedTests=false test

cd eladmin-web
npm run lint
npm run test:unit -- --runInBand tests/unit/api/login.spec.js
npm run build:prod
```
