# 文档目录

该目录用于按类别存放项目文档。

## 文档索引

- [项目启动流程](./项目启动流程.md)：前后端本地启动、环境变量、端口检查与常见启动注意事项。
- [交易分析模块](./交易分析模块.md)：BTC 事件合约交易分析功能的业务背景、代码位置、OCR、K线图片和开发注意事项。
- [代码生成流程](./代码生成流程.md)：以 `invest_trade_analysis` 为例，说明通过系统代码生成器生成前后端 CRUD 的流程。

## 建议分类

- `backend/`：后端设计、接口、启动与部署说明。
- `frontend/`：前端页面、组件、构建与发布说明。
- `database/`：数据库表结构、初始化脚本、迁移记录。
- `operations/`：运维、环境配置、故障排查记录。
- `requirements/`：需求说明、业务规则、流程文档。
