# 文档目录

该目录用于按类别存放项目文档。

## 两个项目的文档归属

`eladmin-mp` 提供后端服务及管理端，`eladmin-h5` 提供用户端 H5 应用。
跨项目的业务规则、数据库设计、接口约定、联调和部署说明统一维护在本目录。
H5 框架版本、启动命令、构建和官方升级记录维护在 H5 仓库，不重复复制。

- [项目协作与文档维护](./项目协作与文档维护.md)：项目职责、文档归属与同步规则。
- [H5 项目入口](https://github.com/Tingnichui/eladmin-h5)：私有仓库，需要仓库访问权限。
- [H5 框架版本与运行](https://github.com/Tingnichui/eladmin-h5/blob/master/docs/框架版本与运行.md)：H5 工程操作说明。

## 建议分类

- `backend/`：后端设计、接口、启动与部署说明。
- `frontend/`：前端页面、组件、构建与发布说明。
- `database/`：数据库表结构、初始化脚本、迁移记录。
- `operations/`：运维、环境配置、故障排查记录。
- `requirements/`：需求说明、业务规则、流程文档。
