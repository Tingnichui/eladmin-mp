# 项目启动流程

本文档用于新会话或新电脑上快速启动本项目的前后端服务。

## 1. 启动前确认

启动前先确认以下信息，不同电脑可以使用不同路径：

- Java：需要 Java 8。
- Maven：使用本机 Maven，并确认 `settings.xml` 与本地仓库路径。
- Node.js / npm：用于启动 `eladmin-web` 前端。
- 配置解密密钥：启动后端前必须向项目负责人确认 `JASYPT_ENCRYPTOR_PASSWORD`。

不要把个人机器上的 Java、Maven、Node、数据库密码等配置写死到代码或提交到仓库。

建议 PowerShell 终端显式使用 UTF-8 输出，避免中文日志乱码：

```powershell
$OutputEncoding = [Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
```

## 2. 后端启动

后端目录为：

```powershell
cd <项目根目录>\eladmin
```

设置当前终端环境变量：

```powershell
$env:JAVA_HOME = '<Java 8 安装目录>'
$env:MAVEN_HOME = '<Maven 安装目录>'
$env:MAVEN_OPTS = '-Dfile.encoding=UTF-8'
$env:Path = "$env:JAVA_HOME\bin;$env:MAVEN_HOME\bin;$env:Path"
$env:JASYPT_ENCRYPTOR_PASSWORD = '<配置解密密钥>'
```

每次启动后端前，先从 `eladmin` 目录执行一次多模块清理构建安装，确保旧 `target` 构建产物被清理、各业务模块 jar 已更新到本地 Maven 仓库：

```powershell
& "$env:MAVEN_HOME\bin\mvn.cmd" `
  -s '<Maven settings.xml 路径>' `
  '-Dmaven.repo.local=<Maven 本地仓库路径>' `
  -DskipTests `
  clean install
```

从 `eladmin` 父目录启动 `eladmin-system` 模块：

```powershell
& "$env:MAVEN_HOME\bin\mvn.cmd" `
  -s '<Maven settings.xml 路径>' `
  '-Dmaven.repo.local=<Maven 本地仓库路径>' `
  -pl eladmin-system `
  -DskipTests `
  spring-boot:run
```

如果需要由 Codex 后台启动后端，可将 Maven 输出重定向到日志文件：

```powershell
New-Item -ItemType Directory -Force -Path '<项目根目录>\runtime-logs' | Out-Null

Start-Process -FilePath "$env:MAVEN_HOME\bin\mvn.cmd" `
  -ArgumentList @(
    '-s',
    '<Maven settings.xml 路径>',
    '-Dmaven.repo.local=<Maven 本地仓库路径>',
    '-pl',
    'eladmin-system',
    '-DskipTests',
    'spring-boot:run'
  ) `
  -WorkingDirectory '<项目根目录>\eladmin' `
  -RedirectStandardOutput '<项目根目录>\runtime-logs\backend.out.log' `
  -RedirectStandardError '<项目根目录>\runtime-logs\backend.err.log' `
  -WindowStyle Hidden
```

注意：

- `spring-boot:run` 不要直接跑在父 `pom` 上。
- 使用 `-pl eladmin-system` 指定启动模块。
- 不建议把 `-am` 和 `spring-boot:run` 混在一起使用；默认先执行上面的 `clean install`，再启动服务。
- 默认后端端口为 `11280`。

后端启动后可检查：

```powershell
Invoke-WebRequest http://127.0.0.1:11280/auth/code -UseBasicParsing
```

## 3. 前端启动

前端目录为：

```powershell
cd <项目根目录>\eladmin-web
```

首次启动或依赖变化后安装依赖：

```powershell
npm install
```

启动开发服务：

```powershell
npm run dev
```

默认前端地址：

```text
http://127.0.0.1:8013/
```

如果需要由 Codex 后台启动前端，优先直接调用 Vue CLI：

```powershell
Start-Process -FilePath '<Node.js 安装目录>\node.exe' `
  -ArgumentList @(
    'node_modules\@vue\cli-service\bin\vue-cli-service.js',
    'serve',
    '--host',
    '0.0.0.0',
    '--port',
    '8013'
  ) `
  -WorkingDirectory '<项目根目录>\eladmin-web' `
  -RedirectStandardOutput '<项目根目录>\runtime-logs\frontend.out.log' `
  -RedirectStandardError '<项目根目录>\runtime-logs\frontend.err.log' `
  -WindowStyle Hidden
```

前端启动后可检查：

```powershell
Invoke-WebRequest http://127.0.0.1:8013 -UseBasicParsing
```

前端页面能打开不代表后端已联通，建议再检查一次前端代理到后端的验证码接口：

```powershell
Invoke-WebRequest http://127.0.0.1:8013/auth/code -UseBasicParsing
```

## 4. 常见问题

### 后端提示找不到主类

如果 Maven 报错 `Unable to find a suitable main class`，通常是把 `spring-boot:run` 跑在了父 `pom` 上。

处理方式：回到 `eladmin` 目录，并使用 `-pl eladmin-system spring-boot:run`。

### 后端提示依赖类不存在

如果只启动 `eladmin-system` 时报 `FileProperties`、`SpringContextHolder`、`EmailVo`、`RsaProperties` 等类不存在，通常是依赖模块还没有编译安装到本地 Maven 仓库。

处理方式：先在 `eladmin` 目录执行：

```powershell
& "$env:MAVEN_HOME\bin\mvn.cmd" `
  -s '<Maven settings.xml 路径>' `
  '-Dmaven.repo.local=<Maven 本地仓库路径>' `
  -DskipTests `
  clean install
```

构建成功后，再执行 `-pl eladmin-system spring-boot:run`。

### 前端代理请求失败

如果前端日志出现 `Proxy error: Could not proxy request auth/code ... ECONNREFUSED`，说明前端已启动，但后端 `11280` 还没有启动成功。

处理方式：先检查后端日志与端口，确认 `http://127.0.0.1:11280/auth/code` 返回 `200` 后，再刷新前端页面。

### 配置加解密

项目内已有测试类：

```text
me.zhengjie.JasyptTests
```

如果需要处理加密配置，优先使用该测试类中的加解密方法，不要临时写一套新的加解密逻辑。

### 端口占用

检查端口占用：

```powershell
Get-NetTCPConnection -ErrorAction SilentlyContinue |
  Where-Object { $_.LocalPort -in 8013,11280 } |
  Select-Object LocalAddress,LocalPort,State,OwningProcess
```

需要确认监听进程时：

```powershell
Get-NetTCPConnection -ErrorAction SilentlyContinue |
  Where-Object { $_.LocalPort -in 8013,11280 -and $_.State -eq 'Listen' } |
  ForEach-Object {
    $process = Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue
    [PSCustomObject]@{
      LocalAddress = $_.LocalAddress
      LocalPort = $_.LocalPort
      State = $_.State
      PID = $_.OwningProcess
      Process = $process.ProcessName
    }
  }
```

## 5. 推荐启动顺序

1. 确认 Java、Maven、Node、`JASYPT_ENCRYPTOR_PASSWORD`。
2. 执行后端 `clean install`。
3. 启动后端 `eladmin-system`，确认 `11280` 可访问。
4. 启动前端 `eladmin-web`，确认 `8013` 可访问。
5. 检查 `http://127.0.0.1:8013/auth/code`，确认前端代理后端正常。
6. 打开 `http://127.0.0.1:8013/` 登录系统。
