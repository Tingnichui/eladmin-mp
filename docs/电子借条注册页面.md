# 电子借条注册页面

最新业务与部署说明见[乐享借注册开放](./乐享借注册开放.md)。

## 邀请注册回跳（2026-10-11）

未登录用户打开 `/#/notes/join?reference=…` 后，登录页通过 `redirect` 保留完整邀请路径。“立即注册”和注册页的“立即登录”继续传递该路径；注册自动登录成功后返回原签署页。自动登录失败时，关闭提示进入登录页，手动登录成功后仍返回同一份邀请。已有会话过期时，清理会话也保留原路径。普通注册未带回跳参数时仍返回首页。

登录、注册共用站内回跳校验，拒绝站外地址、反斜杠、控制字符与登录/注册循环路径，保留邀请定位串的编码。回到签署页后仍需本人核对条款并手写确认，不自动提交签署。

验证：3 项回跳规则测试、类型检查、ESLint、Stylelint及生产构建通过；隔离浏览器以合成接口验证注册自动登录成功、自动登录失败后手动登录、已有会话过期三条流程，定位串完整保留，未注册真实账号或写入真实借条。

## 当前流程

H5 页面为 src/views/register.vue，开发地址 http://127.0.0.1:9000/#/register。

姓名、18位身份证、登录密码及确认密码必填。密码至少6个字符，当前继承框架512位RSA密钥，UTF-8最多53字节；公网上线前应升级密钥并启用HTTPS。确认密码仅前端校验，不存数据库。手机号、昵称和邮箱不要求填写。

用户协议及隐私政策、独立实名核验授权分别主动勾选，默认不选。三份正文由本地后端 /api/iou/auth/policies 返回，以纯文本弹窗展示，不依赖公网域名访问。首次加载失败时点击协议可重新加载。注册要求协议版本一致及年满18周岁。

点击注册先校验表单，再展示通用安全验证弹窗。验证码失败在弹窗内提示并刷新图片，成功取得一次性凭证才请求 /api/iou/auth/register。身份核验失败、协议加载故障等通过居中“注册提示”弹窗展示，字段错误仍展示在对应输入框旁。

后端调用云账户姓名与身份证二要素核验，成功后事务内创建 sys_user 及关联 iou_user；一个身份证一个账号。密码只保存到 sys_user，身份证加密保存并使用固定HMAC密钥查重。仅标记二要素已认证，不伪造手机号三要素、人脸或活体认证结果。

注册响应201，包含 loginCaptcha。前端继续复用 /auth/login、保存令牌及必要显示信息，并跳转主页 /，不二次弹验证码。自动登录失败时明确告知注册成功，关闭提示后进入登录页，不重复注册。

## 核验与限制

云账户组件为 me.zhengjie.iou.plugins.YzhIdentityVerifier，使用 /authentication/verify-id。复用原生产配置，凭据以Jasypt ENC密文保存，无新增SDK，不自动重试收费调用。数脉工具保留备用，不参与当前注册流程。

按用户要求，不设置新增的注册、IOU登录或验证码频率限制，不再使用五分钟身份核验锁。每次重新提交可能再次收费。验证码单次消费、身份查重、事务及唯一约束保留。

当前多数云账户非成功码仍合并为通用错误，日志对非四位数字码记录unknown，尚不能可靠区分信息不匹配、无记录或供应商权限/额度故障。不得据此断定某一字段错误，也不得直接展示供应商原始响应中的身份信息。

## 数据库与验证

旧版且 iou_user 为空的环境执行 sql/iou_registration_migration.sql，只能执行一次，已有借条账号禁止直接执行。新环境先初始化 sql/eladmin.sql、sql/iou_user.sql，再执行 sql/iou_registration_seed.sql；固定ID冲突必须停下检查，不覆盖已有对象。两种初始化方式不能重复执行种子数据。

固定部门、岗位、角色为920001，借条角色仅授权 iou:profile:read，不授予后台管理权限。iou_user与sys_user一对一关联，删除系统借条账号受限，停用走sys_user.enabled。

已运行后端构建与单元测试、管理端lint、H5类型检查及生产构建；浏览器验证了协议弹窗、验证码错误留在安全验证弹窗并刷新。自动登录逻辑有聚焦单元测试，不据此宣称已完成新账号的全流程收费验收。
