# 电子借条注册页面

## 注册约定

姓名、身份证号和登录密码为必填；手机号暂不要求，注册页不展示手机号输入框。
确认密码只用于前端校验，不作为数据库字段。一个身份证对应一个账号，后端接入时使用身份证 HMAC 唯一索引约束重复注册。
注册与实名认证分开；注册填写证件信息不表示完成实名认证。后续绑定手机号进行姓名、身份证号、手机号三要素认证。
用户可用身份证号登录，已绑定的手机号也可作为登录账号。

## 页面与交互

页面代码位于 H5 项目的 `apps/iou/src/views/register.vue`，预览地址为 `http://127.0.0.1:9000/#/register`。
采用蓝白配色、浅色背景及白色表单卡片，提供以下字段：

| 字段 | 交互 |
| --- | --- |
| 真实姓名 | 必填，失焦与提交时校验 |
| 身份证号 | 必填，18 位格式校验，末位允许 X/x；提示可作为登录账号 |
| 登录密码 | 6–72 位，支持显示或隐藏 |
| 确认密码 | 必须与登录密码一致，支持显示或隐藏 |
| 协议勾选 | 默认未勾选，用户主动勾选后才通过表单校验 |

提供登录入口与用户协议、隐私政策入口。协议正文尚待确认，目前弹窗仅标记待提供。
页面只实现预览和前端校验，不请求注册接口，不持久化密码或证件，不模拟注册成功。
配套登录页已替换框架演示页面，见[电子借条登录页面](./电子借条登录页面.md)；目前均为页面预览，尚未调用借条用户接口。

## 已实现的二要素核验能力

### 数脉（后续注册优先使用）

- 工具类为 `eladmin-iou` 的 `me.zhengjie.iou.plugins.ShumaiUtils`，由 Spring 注入后调用 `iDCardVerify(姓名, 身份证号)`。
- 依据[官方接口文档](https://www.shumaiapi.com/productDetail/13/apidoc)封装 HTTPS POST 表单请求至 `/v4/id_card/check`；使用毫秒时间戳和 `MD5(appid&timestamp&appSecurity)` 的 32 位小写签名。未找到可确认的官方 Java Maven SDK，暂复用项目现有 HTTP 能力。
- `application.yml` 的 `iou.shumai` 测试和生产共用；AppID、AppSecurity 均以 Jasypt `ENC(...)` 保存，解密密码从环境提供。
- 必须同时满足 HTTP 200、`success=true`、`code=200`；其中 `data.result=0` 返回 true，1（不一致）返回 false，2（无记录）及其他异常抛出异常。调用方必须检查返回值，false 不得继续注册。
- 权限、余额不足和服务错误不会被解释为身份不一致。工具类不输出姓名、证件、凭据、供应商原始响应，不自动重试付费请求，不跟随重定向。
- 不在启动或单元测试时自动真实调用；未配置 `iou.shumai.url` 时不启用组件。目前仅实现供应商工具类，尚未接入 H5 注册入口；活体、人脸核验尚未实现。
- 2026-10-10 使用已授权的信息完成一次真实请求，返回业务码 `605`（次数不足，请购买套餐），尚未取得身份一致性结果。需在数脉控制台确认二要素产品额度后再验证。

### 云账户（保留原能力）

- 后端组件为 `eladmin-iou` 的 `me.zhengjie.iou.plugins.YzhIdentityVerifier`，调用 `iDCardVerify(姓名, 身份证号)`。
- 组件直接向云账户 `/authentication/verify-id` 发起请求，不引入云账户 SDK；按原 SDK 协议使用 3DES 加密和 RSA 签名。
- `application.yml` 的 `iou.yzh` 沿用原项目 `yzh-test.properties` 配置，测试和生产共用；AppKey、3DES 密钥和 RSA 私钥均以 Jasypt `ENC(...)` 保存。
- 原配置地址为 `https://api-service.yunzhanghu.com`，文件名不能证明它是沙箱；调用前应确认商户权限、费用及测试身份授权。
- 仅 HTTP 200 且业务码 `0000` 返回成功，其他响应抛出异常；不将供应商原始消息、证件或密钥写入业务日志。
- 此组件尚未接入 H5 注册入口，不会在应用启动时自动请求外部服务；未配置 `iou.yzh.url` 的环境不启用组件。

## 注册接口待办

- 当前 `iou_user.mobile` 仍为必填，需要迁移为允许 NULL，保留唯一索引；未绑定时用 NULL，不能用空字符串。

- 前端格式校验不等于证件真实性核验；身份证校验与认证结果以后端为准。
- 接入独立的 H5 注册、登录和鉴权接口，确认正式协议后再开放真实注册。
