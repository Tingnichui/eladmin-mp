# 币本位合约统计页面

本文档记录币本位合约统计的一期范围、数据口径和代码位置。

## 1. 一期范围

- 独立菜单“投资管理 → 币本位统计”。
- 支持账户选择、`BTCUSD_PERP`、`LONG/SHORT/BOTH` 持仓方向。
- 支持查询和指定账户、指定合约的增量成交同步。
- 展示实时仓位、账户资产、全部已平仓周期成交汇总，以及价格区间和逐笔开仓分布。
- 支持市价、限价开平仓，以及当前挂单查询和单笔撤单。
- 暂不提供条件止盈止损、杠杆调整和保证金调整。币安迁移后的条件单需另接 `/dapi/v1/algoOrder`。

## 2. 接口

```text
GET /api/binanceCoinFuturesTradeInfo/stats
GET /api/binanceCoinFuturesTradeInfo/stats/position
GET /api/binanceCoinFuturesTradeInfo/stats/account
GET /api/binanceCoinFuturesTradeInfo/stats/closed-summary
PUT /api/binanceCoinFuturesTradeInfo/syncSelected
POST /api/binanceCoinFuturesTradeInfo/order
GET /api/binanceCoinFuturesTradeInfo/order
GET /api/binanceCoinFuturesTradeInfo/open-orders
DELETE /api/binanceCoinFuturesTradeInfo/order
```

查询参数为 `uid`、`symbol` 和 `positionSide`；同步参数为 `uid` 和 `symbol`。一期仅接受 `BTCUSD_PERP`。

页面查询时并行加载 `/stats/position` 和 `/stats/account`；前者返回实时仓位、合约规格及当前未平仓分布，后者仅返回账户资产。“全部汇总”弹层首次打开时才调用 `/stats/closed-summary`，避免历史资金费查询阻塞页面主体。旧 `/stats` 暂时保留为兼容聚合接口。

实时仓位接口并行读取合约规格、仓位和标记价格，总等待时间不超过 5 秒。合约规格缓存 60 分钟；实时仓位与标记价格保留 10 分钟故障缓存。发生超时或外部接口异常时，页面可展示最近一次缓存数据，但返回 `realtime=false`，前端必须禁止下单。三个拆分接口的前端请求超时均为 15 秒，避免沿用全局 20 分钟超时造成长时间遮罩。

后端调用币安 COIN-M 的 `positionRisk`、`account`、`exchangeInfo`、`premiumIndex`、`userTrades` 和 `income` 接口。顶部仓位指标以币安实时数据为准；本地成交用于识别全部已完整平仓周期，并重建当前周期的逐笔未平仓分布。

下单请求使用 `OPEN/CLOSE + LONG/SHORT` 表达业务动作，由服务端转换为币安的 `BUY/SELL`。服务端会读取账户持仓模式：双向持仓传 `LONG/SHORT` 且不传 `reduceOnly`；单向持仓传 `BOTH`，平仓时传 `reduceOnly=true`。平仓前会重新查询实时仓位并限制最大张数。每笔订单使用服务端生成的 `newClientOrderId`；POST 结果不确定时先按客户端订单号查询，不直接重复下单。

页面同时展示张数和 BTC。合约面值取自 `exchangeInfo.contractSize`；市价单按标记价格、限价单按委托价计算 `预计 BTC = 张数 × 合约面值 ÷ 参考价格`，预估保证金再除以当前杠杆。挂单的已成交 BTC 优先使用币安返回的 `cumBase`，没有实际成交数据时才显示估算值。

“全部汇总”中的已实现盈亏、手续费、资金费和净盈亏以 USD 为主展示，按页面当前 BTCUSD 标记价格折算；悬浮金额可查看后端返回的原始 BTC。标记价格不可用时自动回退为 BTC 展示。该折算只用于增强可读性，不改变币本位原始统计口径，也不代表现金已经兑换为 USD。

## 3. 统计口径

- `qty` 表示合约张数，`baseQty` 表示基础币数量，两者不能混用。
- 已实现盈亏直接汇总成交记录的 `realizedPnl`。
- 手续费只汇总与保证金币种一致的记录；其他币种给出告警。
- 仓位数量每次回到 0 视为完成一个平仓周期；汇总只包含这些完整周期，当前尚未平完的周期不计入。
- 全部已平仓周期净盈亏为 `已实现盈亏 + 资金费 - 手续费`。
- 未平仓批次按成交时间和成交 ID 进行 FIFO 展示层重建。
- 反向合约未实现盈亏按合约面值、开仓价和标记价格计算，单位为保证金币种。
- `BOTH` 单向持仓无法仅凭成交方向可靠识别开平关系，因此暂不提供已平仓周期汇总和逐笔未平仓分布。

## 5. 部署说明

部署页面前需要重新执行可重复运行的菜单脚本。统计页面权限沿用 `binanceCoinFuturesTradeInfo:list`，同步按钮需要 `binanceTradeInfo:sync`，下单、挂单查询及撤单需要 `binanceCoinFuturesTradeInfo:order`。

## 6. 已接受的当前边界

- 全部已平仓周期资金费按已平仓成交的首尾时间查询 `/dapi/v1/income`，按一年时间窗口及每页 1000 条分页读取，并按 `tranId` 去重。
- 已平仓汇总以“账户、合约、方向、最后一条已平仓成交 ID”为缓存版本，缓存 30 分钟；同步产生新的完整平仓周期后会自然切换缓存版本。
- 币安资金费流水按交易对返回，不含持仓方向；同一时间同时持有多空仓位时，资金费无法按 `LONG/SHORT` 精确拆分。
