# 电子借条编号规则

更新：2026-10-11。

新建借条首次保存时生成 `JTYYYYMMDD-NNNNNN`，例如 `JT20261011-002020`。日期固定使用北京时间，末尾是分时段时间编码，不代表真实用户数量或签署数量；界面保持“借条编号”标签。

## 时间编码

| 北京时间 | 编码基准 |
| --- | --- |
| 00:00 | 000100 |
| 06:00 | 000220 |
| 09:00 | 000820 |
| 12:00 | 002020 |
| 18:00 | 004420 |
| 23:00 | 005420 |
| 次日 00:00 前 | 趋近 005460 |

各时段按秒线性插值并向下取整。夜间推进较慢，白天推进较快。实际分配值为 `max(时间基准, 当天上次分配值 + 1)`，因此同一时刻多人保存仍生成不同编号；时钟在同一天回拨也不降低已分配值。每日日期独立，不使用随机起始值。六位容量用尽时拒绝创建，不回绕。

## 持久化与兼容

- `iou_note_number` 每个日期一行，主键日期。数据库行锁串行分配，多个服务实例共用同一数据库时仍保持唯一。
- 分配、草稿及还款计划写入同一事务；创建失败一起回滚。创建幂等命中已保存借条时直接返回原编号，不再分配。
- 编号仅在首次创建时生成。修改草稿、签署、生成合同和下载沿用原编号。历史 UUID 编号不重写，已签署条款快照和文件保持原样。
- 日计数表不能随意清空或降低数值；数据库备份恢复必须与借条表一致。原借条表编号唯一索引继续保留。
