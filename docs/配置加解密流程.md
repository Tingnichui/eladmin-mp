# 配置加解密流程

本文档说明本项目配置项中 `ENC(...)` 的加密、解密方式。适用于本地开发或排查配置问题。

## 1. 前置条件

本项目使用 Jasypt 处理配置加密。配置位置：

```text
eladmin/eladmin-system/src/main/resources/config/application.yml
```

核心配置：

```yaml
jasypt:
  encryptor:
    password: ${JASYPT_ENCRYPTOR_PASSWORD}
```

执行加解密前必须先向项目负责人确认当前环境的 `JASYPT_ENCRYPTOR_PASSWORD`。不要把真实密钥写入文档、代码、提交信息或聊天记录。

## 2. 本机工具路径

本机 Java 8：

```powershell
$java = 'C:\MyProgram\develop\Java\java1.8_8u361\bin\java.exe'
```

Jasypt CLI jar：

```powershell
$jasypt = 'C:\MyProgram\develop\Maven\apache-maven-3.5.4\repo\org\jasypt\jasypt\1.9.3\jasypt-1.9.3.jar'
```

如果路径不存在，先检查 Maven 本地仓库是否已下载 `org.jasypt:jasypt:1.9.3`。

## 3. 通用参数

项目当前使用 Jasypt 默认参数：

```text
algorithm=PBEWITHHMACSHA512ANDAES_256
keyObtentionIterations=1000
saltGeneratorClassName=org.jasypt.salt.RandomSaltGenerator
ivGeneratorClassName=org.jasypt.iv.RandomIvGenerator
stringOutputType=base64
```

这些参数需要和应用运行时保持一致，否则解密会失败。

## 4. 加密配置

先在当前 PowerShell 终端设置密钥：

```powershell
$env:JASYPT_ENCRYPTOR_PASSWORD = '<配置解密密钥>'
```

执行加密：

```powershell
& $java -cp $jasypt org.jasypt.intf.cli.JasyptPBEStringEncryptionCLI `
  input='要加密的明文' `
  password=$env:JASYPT_ENCRYPTOR_PASSWORD `
  algorithm='PBEWITHHMACSHA512ANDAES_256' `
  keyObtentionIterations=1000 `
  saltGeneratorClassName='org.jasypt.salt.RandomSaltGenerator' `
  ivGeneratorClassName='org.jasypt.iv.RandomIvGenerator' `
  stringOutputType='base64'
```

命令输出中 `----OUTPUT----------------------` 后面的内容就是密文。写入配置时需要包成：

```text
ENC(密文)
```

## 5. 解密配置

解密时 `input` 填 `ENC(...)` 里面的密文，不要带 `ENC(` 和 `)`：

```powershell
& $java -cp $jasypt org.jasypt.intf.cli.JasyptPBEStringDecryptionCLI `
  input='ENC里面的密文' `
  password=$env:JASYPT_ENCRYPTOR_PASSWORD `
  algorithm='PBEWITHHMACSHA512ANDAES_256' `
  keyObtentionIterations=1000 `
  saltGeneratorClassName='org.jasypt.salt.RandomSaltGenerator' `
  ivGeneratorClassName='org.jasypt.iv.RandomIvGenerator' `
  stringOutputType='base64'
```

如果不想把 CLI 的参数区完整打印出来，可以在 PowerShell 中只提取输出结果：

```powershell
$out = & $java -cp $jasypt org.jasypt.intf.cli.JasyptPBEStringDecryptionCLI `
  input='ENC里面的密文' `
  password=$env:JASYPT_ENCRYPTOR_PASSWORD `
  algorithm='PBEWITHHMACSHA512ANDAES_256' `
  keyObtentionIterations=1000 `
  saltGeneratorClassName='org.jasypt.salt.RandomSaltGenerator' `
  ivGeneratorClassName='org.jasypt.iv.RandomIvGenerator' `
  stringOutputType='base64'

for ($i = 0; $i -lt $out.Count; $i++) {
  if ($out[$i] -eq '----OUTPUT----------------------') {
    $out[($i + 1)..($out.Count - 1)] |
      Where-Object { $_.Trim() } |
      Select-Object -First 1
    break
  }
}
```

## 6. 测试环境数据库链接

测试环境 master 数据源配置在：

```text
eladmin/eladmin-system/src/main/resources/config/application-dev.yml
```

字段位置：

```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: ENC(...)
```

解密时只解 `ENC(...)` 内部的密文即可。数据库用户名、密码也可能是 `ENC(...)`，但除非排查需要，不要随意解密或传播。

## 7. 注意事项

- Jasypt CLI 会打印参数区，其中包含 `password`。使用后不要把完整终端输出提交到仓库或发到公共渠道。
- 新增加密配置时，只提交 `ENC(...)`，不要提交明文。
- 解密出来的数据库链接、账号、密码、Webhook、Token、API Key 等都按敏感信息处理。
- `me.zhengjie.JasyptTests` 仍可作为代码内参考，但日常临时加解密优先使用本文档的纯命令方式。
