# 项目协作与文档维护

## 项目职责

| 项目 | 职责 | 本地目录 |
| --- | --- | --- |
| eladmin-mp | Spring Boot 后端、数据库、Vue 2 管理端 | `C:\project\eladmin-mp` |
| eladmin-h5 | Fantastic-mobile Pro 用户端、多 H5 应用 | `C:\project\eladmin-h5` |

管理端与 H5 通过 HTTP 接口访问后端，两个项目独立提交、构建和部署。
H5 多个业务应用放在 `apps/<应用名>`，共用 `packages/`，无需每个业务都新建仓库。
H5 使用独立私有仓库保存 Pro 源码。

## 文档归属

| 内容 | 维护位置 |
| --- | --- |
| 业务规则、借条生命周期、表设计、数据库迁移说明 | `eladmin-mp/docs/`，SQL 原文件放 `eladmin-mp/sql/` |
| 后端接口、鉴权、权限、菜单、生成流程 | `eladmin-mp/docs/` |
| 前后端联调、环境约定、跨项目部署与验收 | `eladmin-mp/docs/` |
| H5 框架版本、依赖、启动、构建、官方手动升级 | `eladmin-h5/docs/` |
| H5 组件和应用内部开发说明 | `eladmin-h5/docs/` 或对应组件目录 |

同一内容只维护一份，另一仓库用链接引用。两边 README 作为入口；新增文档时同步更新所在仓库的文档索引。
修改接口或业务规则时先更新本仓库的对应说明，H5 工程操作变化更新 H5 文档。
涉及两个项目的变更分别提交，提交说明注明配套变更；接口尚未实现时明确标记，避免将设计当成可调用接口。
文档不记录真实凭据、密钥或用户证件信息。

## 当前电子借条进度

- 独立表 `iou_user`、`iou_note` 已建立；后台 CRUD、菜单和字典初始化已完成，见[电子借条后台初始化](./电子借条后台初始化.md)。
- 目前提供 `/api/iouUser`、`/api/iouNote` 管理接口，使用管理端权限体系。
- H5 已有[注册页预览](./电子借条注册页面.md)，首页与登录逻辑仍为框架演示；用户端登录、三要素认证、支付、电子签约及对应接口尚未实现。
- 后续 H5 接入时另行设计用户端接口与鉴权，不能直接使用管理员接口。
