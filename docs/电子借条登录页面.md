# 电子借条登录页面

## 当前行为

H5页面为 apps/iou/src/views/login.vue，开发地址 http://127.0.0.1:9000/#/login。

目前仅支持身份证号与密码登录；手机号登录须后续短信验证并唯一绑定后开放。登录前展示公共验证码弹窗，校验失败在弹窗内处理，成功获得短时一次性凭证后调用原 /auth/login 接口，传入 loginType=IOU。

后端通过身份证HMAC查询关联的sys_user，再复用原密码编码器、令牌、在线会话和退出机制。后台用户与IOU用户按账号类型隔离，不能仅凭增加角色绕过后台接口隔离。

浏览器仅保存令牌、显示姓名等必要信息，不保存身份证或密码。/auth/info和/api/iou/app/me返回本人必要资料，不暴露密码摘要、身份证密文或HMAC。本人资料由登录的sys_user ID确定，不接受客户端指定其他用户ID。

手动登录保留安全的站内redirect，默认到/user。注册后自动登录跳转主页/；注册接口返回新的loginCaptcha，避免重复消费注册验证码。自动登录失败时不重复注册，转手动登录。

验证码校验入口为/api/security/captcha/verify，匿名可访问。成功凭证两分钟有效，仅能消费一次，不能用凭证续期。未授权或服务不可用不得伪装为验证码错误；公共接口也不显示“登录状态已过期”。
